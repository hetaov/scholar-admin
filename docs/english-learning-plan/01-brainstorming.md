# 第一步:发散思维 —— 影响个人英语学习的全部因素

> 目的:**穷举**影响"一个学生能否学好英语"的所有因素,暂时不做筛选。
> 方法:按「学习者 → 行为 → 内容 → 结果 → 环境 → 产品」六大维度发散。
> 每个因素标注 `[数据可得]`(现有数据可算)或 `[需采集]`(需要新增埋点/字段),为第二步收敛做准备。

---

## A. 学习者自身因素(内因)

| # | 因素 | 说明 | 数据可得性 |
|---|------|------|-----------|
| A1 | 学习动机 | 内在(兴趣)/ 外在(考试、家长要求) | 需采集(问卷/画像) |
| A2 | 学习目标 | 应试 / 日常交流 / 兴趣拓展 | 需采集 |
| A3 | 基础水平 | 词汇量、语法基础、语音基础 | 可推导(正确率均值) |
| A4 | 年龄段 | 认知与注意力特点(本项目为小学生) | 现有 |
| A5 | 学习风格 | 视觉 / 听觉 / 动觉偏好 | 需采集 |
| A6 | 记忆能力 | 受遗忘曲线影响,个体差异大 | 可推导(复习间隔表现) |
| A7 | 专注时长 | 单次能保持的注意力时间 | 可推导(单次学习时长分布) |
| A8 | 自律程度 | 能否坚持每日学习 | 可推导(打卡/连续天数) |
| A9 | 自我效能感 | 对"我能学会"的信心 | 需采集 |
| A10 | 情感因素 | 焦虑、挫败感、畏难情绪 | 需采集(主观反馈) |

| # | 因素 | 说明 | 数据可得性 |
|---|------|------|-----------|

| B2 | 单次学习时长 | 每次会话持续多久 | **现有** |
| B3 | 学习频次 | 每天学几次、间隔多久 | 现有(可统计) |
| B4 | 学习时间分布 | 早晨/晚上、是否规律固定 | 现有(时间戳) |
| B5 | 学习节奏 | 集中突击 vs 滚动持续 | 可推导(频次×间隔) |
| B6 | 学习顺序 | 按单元顺序 vs 跳学 | 现有(记录序列) |
| B7 | 学习方式 | 跟读/听写/默写/翻译/造句 | 需采集(记录 type) |

## F. 产品/系统因素(项目可实现的设计杠杆)

| # | 产品机制 | 作用于哪些因素 | 实现成本 |

| F5 | 薄弱点智能推荐 | D5, D6 → 精准补漏 | 中 |
| F6 | 每日学习目标/计划 | B3, C4, A2 → 固化习惯 | 中 |
| F7 | 连续打卡与日历热力图 | A8 → 行为激励 | 低 |

## 发散小结

- 共梳理 **6 大维度、约 70 个因素**,其中项目**可直接计算/统计**的约 30 个(`[现有]`/`[现有/扩展]`),**需要新增采集**的约 40 个。
- 影响学习效果的核心因果链:**规律的行为(频次×时间×重复)→ 高掌握度 → 低遗忘率 → 成就感 → 更强的动机**,形成正向循环。
- 项目最有发挥空间的是 **F 维度(产品机制)**,因为它能主动作用于 A/B/D 多个因素,而 E 维度的多数因素项目无法控制。
