## 一句话结论

从 60+ 个因素中收敛出 **4 个核心功能**(用户已提出)为 P0 基线,补充 **滚动学习调度** 为 P1 差异化核心,形成「**学得久 + 学得多 + 记得牢**」的功能闭环:

1. **学习时间** —— 用户级别累计学习时长统计(接口已实现)
2. **学习进度** —— textbook / unit / sentence 三级进度(接口已实现)
3. **学习次数** —— 每个句子的学习次数与重复曝光(需扩展字段)
4. **滚动学习** —— 间隔重复调度器,把易忘的句子按遗忘曲线重新推给用户(差异化核心)
